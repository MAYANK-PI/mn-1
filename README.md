## What This Does
This contract implements a counter that can be incremented, set to a specific value, or reset to zero. It demonstrates how Midnight Network handles public state (visible on-chain) and private state (kept confidential) while allowing users to prove correct state transitions without revealing sensitive information.

## Privacy Model
- **What is PUBLIC (on-chain, visible to anyone):**
  - The current counter value stored in the public ledger
  
- **What is PRIVATE (private witness, never on-chain):**
  - The previous counter value before each operation (stored in `lastValue` variable)
  - Any intermediate computation values used during circuit execution
  
- **What the user PROVES without revealing:**
  - That the counter was correctly incremented/decremented/set according to the operation
  - That state transitions follow the defined logic
  - That private values were properly handled without exposing them

## Setup
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local Midnight devnet and deploy the contract:
   ```bash
   npm run setup
   ```
   This will:
   - Start local Midnight devnet services (node, indexer, proof-server)
   - Compile the counter contract
   - Deploy the contract to the local devnet
   - Initialize wallet state

## Run Tests
To run the test suite:
```bash
npm test
```
This executes the Vitest tests in `tests/counter.test.ts` which verify:
- Circuit logic correctness
- Proper state transitions
- Privacy guarantees (private inputs never exposed)
